## Database setup choice

- For a new database, execute `data/B2BWholesaleDB.sql` once in SQL Server Management Studio.
- For an existing database created from the earlier WinForms-only ZIP, execute `data/Upgrade-Existing-Database.sql` once.
- Do not execute the new-database script repeatedly against a database whose tables already exist.
